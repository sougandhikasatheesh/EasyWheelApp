
## Wheelchair Guidance & Assistance System

A disability-focused Android application that empowers wheelchair users to navigate daily life with confidence, safety, and independence.

📌 Overview

EasyWheel is an Android application designed to help wheelchair users locate nearby accessible facilities like wheelchair-friendly toilets, hospitals, repair shops, NGOs, medical shops, and police stations.
The app uses the user's GPS location to show relevant places on a map. It also has an emergency SOS feature to alert caregivers.

📌  Features

- Find nearby wheelchair-friendly facilities using GPS
- View locations on map and list view
- Navigate to places using Google Maps
- Check medicine availability and compare prices across nearby shops
- Emergency SOS alert to caregivers with live location
- Role-based login for users, caregivers, and admin
  
📌  Tech Stack

- Platform: Android
- Languages: Java, Kotlin
- IDE: Android Studio
- Backend: Firebase (Realtime Database, Authentication, Cloud Messaging)
- Maps: Google Maps API
- UI Design: Figma
